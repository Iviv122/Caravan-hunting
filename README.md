# Hunting mod

<img width="613" height="309" alt="screenshot 313" src="https://github.com/user-attachments/assets/0a4ab5cb-53db-43ce-8fcc-e6f993a81c30" />

This mod is for those who are tired of manually hunting in caravan

![example](https://i.imgur.com/Gc3DUiD.png)


If your pawns are capable of butchering and violence + they have ranged weapon, you will be able to hunting while caravanning. It will make them slower and more visible, the process takes 4 hours. After that you will get resources as you would hunt some amount of animals. Also you can't hunt while resting. Butchering efficiency will be count as it would be butchering place.

Everything is customizable besides skills requirements to stay fair.

build
```
git clone https://github.com/Iviv122/Caravan-hunting
cd Source
chmod +x build.sh
./build.sh 
```

use:

- Dotnet 11 Preview

Dependencies:
- HarmonyLib
